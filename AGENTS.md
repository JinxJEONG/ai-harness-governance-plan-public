# Project Agent Instructions

This repository contains reusable governance documentation and checkpoint tools.
Use repository files and current test results as evidence. Run `rake` after
changing the tools or documentation, and preserve checkpoint compatibility.

Keep examples synthetic. Do not commit machine-specific MCP settings, personal
paths, credentials, real project inventories, checkpoint archives or operational
evidence. The phase documents describe procedures; they do not authorize changes
to other repositories, cloud accounts or production systems.
