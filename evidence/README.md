# 실행 증거는 비공개로 보관합니다

공개 배포본에는 실제 fleet 목록, checkpoint 색인, 설정 스캔, 작업 로그, 승인 내역,
PR 상태, 결제·플랜 정보 또는 개인 파일 경로를 포함하지 않습니다.

Phase 문서의 `evidence/<phase>/<project>/...` 경로는 사용자가 별도로 생성할 비공개
실행 기록의 형식입니다. 이 저장소에 완료 증거가 있다는 뜻이 아닙니다.

- 원본 실행 결과는 저장소 밖이나 접근 제한된 비공개 저장소에 보관합니다.
- `.env`, 토큰, 인증 파일 및 checkpoint archive를 커밋하지 않습니다.
- 공개 예제가 필요하면 합성 입력과 예시용 ID로 새로 작성하고 별도로 검사합니다.
- 과거 실행의 승인을 새 작업의 권한으로 해석하지 않습니다.
